# Состояние продукта · отзывы после визита

С 13 ноября 2026 направление продукта — закрытая обратная связь между гостем и заведением. Кассовые интеграции, обслуживание столов, iikoWaiter и бонусные операции исключены из рабочего сценария.

| Возможность | Реализация |
|---|---|
| Вход | Проверка Telegram initData, общая база SQLite, один профиль на Telegram ID |
| Каталог | Индивидуальные карточки заведений, оформление «Свои» и «Эльпастор», личный QR |
| Визит | Подтверждается сотрудником при сохранении анкеты; сканирование отдельно не создаёт посещение |
| Анкета сотрудника | Известные предпочтения, впечатление от общения, отдельный комментарий |
| Анкета гостя | Пять аспектов с вариантами понравилось / не понравилось / не могу оценить, письменный комментарий |
| Ответ команды | Ответ на конкретный отзыв, отображается его автору |
| Приватность | Отзывы гостя — автору и своей команде; заметки о госте — только своей команде |
| Роли | Разработчик добавляет заведения и руководителей; руководитель приглашает сотрудников |
| Надёжность | Транзакции, аудит, ключи повторов, защита от двойной анкеты и устаревшего подтверждения визита |
| История | Старые данные сохраняются; архивные отзывы не становятся публичными |
| Публикация | Проверенный релиз GitHub → автоматическое обновление VPS с резервной копией |

В текущей версии нет публичного рейтинга гостей, публичной ленты отзывов, оплаты, начисления бонусов или чтения кассовых заказов. HTTP-адреса касс и старые команды закрыты; архивный код сохранён для совместимости с прежними данными.

Ограничения: данные обновляются опросом раз в 5 секунд; отправка требует сети. QR содержит постоянный случайный идентификатор, не служит доказательством физического присутствия — сотрудник проверяет имя и сам подтверждает визит.

Перед пилотом нужен отдельный проход на реальных телефонах гостя и сотрудника, включая доступ к камере, повторный вход, плохую связь и просмотр ответа команды. Автоматические браузерные проверки используют тестовые аккаунты и не заменяют такую проверку. Нагрузочное испытание и независимое внешнее хранилище резервных копий остаются отдельными задачами.
