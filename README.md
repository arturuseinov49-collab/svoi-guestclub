# Свои · отзывы после визита

Telegram Mini App для гостей и команд заведений. Гости оценивают посещение по пунктам, а сотрудники запоминают предпочтения гостей в закрытой анкете. Вход через Telegram, общая серверная база и интерфейс для телефонов iOS и Android.

## Как это работает

1. Гость выбирает карточку заведения и показывает личный QR.
2. Сотрудник сканирует QR, проверяет имя и видит историю гостя в своём заведении. Сканирование само по себе не создаёт визит.
3. После посещения сотрудник завершает визит: отмечает известные предпочтения, впечатление от общения и при необходимости пишет комментарий.
4. У гостя появляется анкета: еда, обслуживание, атмосфера, чистота, соотношение цены и качества. Для каждого пункта — «Понравилось», «Не понравилось» или «Не могу оценить». Письменный комментарий необязателен.
5. Команда читает отзыв и может ответить. Гость видит ответ в своей истории.

Отзывы гостей доступны **только автору и команде соответствующего заведения**. Предпочтения и отзывы сотрудников о госте доступны **только команде этого заведения**. Публичной ленты отзывов и общей репутации гостей нет.

## Доступ и заведения

Заведения создаёт разработчик платформы; он оформляет карточку, включает анкеты и назначает руководителя. Руководитель выдаёт сотрудникам одноразовые приглашения. Гость не может самостоятельно получить права сотрудника или владельца. Доступ проверяет сервер при каждом действии, включая повтор ранее отправленной операции.

Каталог сохраняет индивидуальное оформление заведений, включая тестовую карточку «Эльпастора». Публикация карточки и включение анкет управляются отдельно. Для уже опубликованных карточек без нового флага анкеты включены; скрытые старые карточки автоматически не публикуются. Отметка «Тестовая» не означает согласованное коммерческое партнёрство.

## Данные и переход на отзывы

Кассы iiko/r_keeper, столы, переход в iikoWaiter, бонусные начисления и списания отключены. Сервер не запускает кассовый обработчик; `/api/pos/*` и прежние команды начислений/обслуживания возвращают HTTP 410.

Исторические данные не удаляются. Старые отзывы и визиты доступны в истории с прежними границами доступа. Старые финансовые записи остаются в базе для сохранности, но не участвуют в новых визитах. Архивные модули и их тесты сохранены; их наличие в исходниках не означает работающую интеграцию.

Новые визиты, анкеты и ответы хранятся в отдельных массивах `feedbackVisits`, `staffFeedback`, `guestFeedback` внутри `app_state`. SQLite остаётся на схеме 2. Визит и анкета сотрудника сохраняются в одной транзакции с аудитом и квитанцией операции. Повтор после потери ответа не создаёт вторую запись. Один подтверждённый визит допускает один отзыв гостя.

Клиент обновляет данные каждые 5 секунд и при возвращении в приложение. Без сети изменение не объявляется сохранённым. Telegram bearer-токен хранится только в памяти клиента; в SQLite хранится его хеш. QR — случайный идентификатор гостя, а не средство входа.

## Разработка и проверки

Нужны Node.js 22.22+ и npm. SQLite входит в Node.js.

```shell
npm ci
# Скопировать .env.example в .env.local и настроить отдельную тестовую среду.
npm run lint
npm run typecheck
npm test
npm run build
npm run test:ui
npm start
```

Для рабочего входа откройте Mini App через Telegram на HTTPS-адресе. Авторизационного обхода для разработки в опубликованном сервере нет. Браузерные тесты используют отдельную базу и вымышленные Telegram-подписи. Физическую камеру и поведение конкретного Telegram WebView проверяют на телефонах отдельно.

`server/feedback.mjs` — новые бизнес-правила; `src/feedback.ts` — типы и варианты анкеты. Правила профилей и архивная доменная модель генерируются из TypeScript командой `npm run build:server`.

## Публикация

GitHub Actions проверяет код и собирает неизменяемый релиз для точного коммита `main`. VPS проверяет происхождение релиза и хеши, делает резервную копию SQLite, переключает приложение и проверяет здоровье. Секреты и рабочая база хранятся отдельно от релизов и не попадают в Git. Подробнее: [deploy/README.md](deploy/README.md), [DEPLOYMENT.md](DEPLOYMENT.md).

Сайт и Telegram-бот работают отдельными процессами. Бот предоставляет кнопку Mini App и `/start`, `/help`, `/privacy`; рассылок нет.
