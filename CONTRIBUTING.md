Это публичный репозиторий коммерческого проекта. Доступ к исходникам не даёт права распространять собственный код «Своих» или данные заведений; условия указаны в [LICENSE](LICENSE). Компоненты третьих лиц сохраняют свои лицензии.

## Запуск и проверка

Нужен Node.js 22.22 или новее и npm. Установите зависимости командой `npm ci`. Скопируйте `.env.example` в непубликуемый `.env.local` и заполните только настройки своей тестовой среды. Не используйте рабочую базу для разработки.

```shell
npm run lint
npm run typecheck
npm test
npm run build
```

После сборки `npm start` запускает локальный сервер. Реальный вход требует подписанных данных Telegram и HTTPS-адреса Mini App. В рабочей версии нет обхода авторизации. Для браузерных проверок используйте `npm run test:ui`; конфигурация требует установленного Chrome и поднимает изолированный тестовый сервер. Камеру и поведение Telegram WebView дополнительно проверяют на реальных iOS и Android.

`src/domain.ts` и `src/venue-profile.ts` — исходники общих правил. `server/domain.mjs` и `server/venue-profile.mjs` генерируются командами сборки; не редактируйте их вручную. Набор зависимостей зафиксирован в `package-lock.json`. Перед изменением Expo/React Native API прочитайте документацию установленной версии.

## Изменения и публикация

Работайте в отдельной ветке. В описании изменения укажите поведение до и после, способ проверки и ограничения. Изменения бонусных правил, прав доступа, идемпотентности и кассовых адаптеров должны проверяться содержательными тестами. Тестовые личности и токены должны оставаться явно вымышленными.

Перед коммитом просмотрите `git diff --cached` и список файлов. Не добавляйте `.env`, базу, копии, ключи, логи, локальные метаданные агента, приглашения или реальные Telegram ID. Используйте [SECURITY.md](SECURITY.md) при обнаружении утечки.

GitHub Actions запускает lint, TypeScript, серверные/доменные тесты и сборку без секретов. Он не публикует приложение. GitVerse хранит зеркало исходников; успешный запуск GitHub Actions не означает, что проверки запущены в GitVerse. Выкатка выполняется отдельно по [deploy/README.md](deploy/README.md) с резервной копией и проверкой результата.
